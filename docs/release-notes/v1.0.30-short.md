# ClawDao v1.0.30 发版说明（用户版）

> **发布日期**：2026 年 9 月
> **承接**：v1.0.29（CEO 压缩、自动更新双镜像、应用右栏）
> **配套**：[完整 release notes（开发者版）](./v1.0.30.md) · [CHANGELOG.md](../../CHANGELOG.md)

## 一句话总结

**v1.0.30 把数字员工的协作能力做深、把成果预览做顺手、再把整套安全门槛拉高一个档次。**

---

## 这次带来了什么

### 1. 数字员工真正「团队协作」

- **多员工并行**：可以让 CEO 一次召集多位员工同时干活，每个员工分到自己的小任务，CEO 把结果汇总后再回你。
- **员工模板导出 / 导入**：自己做好的员工可以一键打包分享给同事，也可以从别人那里导入现成的员工模板，几秒钟就能上手。
- **CEO 提示词模板**：和 CEO 沟通时可以从常用场景的模板开始，省去想措辞的时间。

### 2. 成果（产物）直接在对话里预览

- **消息里就能看**：员工做完一个文件（网页、图、音频、视频等），点一下就能直接在对话里展开看，不用跳出。
- **右侧多标签预览**：一次想对比多个产物时，右侧可以同时开几个标签页，切换方便，关掉就清空。

### 3. 安全全面加固

- **链接白名单**：从应用里发起的网络请求，现在只允许去往事先约定好的目标（如官方视频站），陌生或可疑地址会被拦下。
- **更严格的本地命令执行**：员工在本地跑命令时，参数会被严格校验，能拦住乱拼的字符串注入。
- **敏感目录默认拒绝**：本地文件系统现在默认不允许触碰密钥目录等敏感位置。
- **审计日志可查**：每次重要操作（启动项目、跑命令、装技能等）都会留下记录，可在「设置 → 审计日志」里查看。
- **敏感操作二次确认**：真正有风险的动作（删项目、覆盖文件等）会弹一个明确的二次确认，避免误操作。

### 4. 体验细节补完

- 拖拽文件夹和文件更稳；CEO 消息里出现的文件链接会智能归类到右侧对应面板。
- 一系列小 bug 修复（终端卡顿、面板空闪、应用列表加载等）。

---

## 升级说明

- **普通用户**：什么都不用做，会自动收到更新。
- **已有员工**：你之前设置的所有员工和对话都保留；如果之前没启用过多员工协作，升级后可以从「员工模板」开始体验。
- **数据无破坏**：旧设置、旧对话、旧员工模板完整保留。
- **审计日志是新的**：升级后第一次启动，「设置」里会多出一个「审计日志」标签，里面是空白的，从现在开始记录。
